# 路口里的 PLC · 手机版长期保存与发布说明

2026-10-13 · 随身课堂 3.0

## 先分清两种保存方式

- **网页文件备份**：独立 HTML 内包含全部课堂内容，没有临时网址和到期日期。保留文件，并备份到电脑、U 盘或网盘，即可长期保存。打开时需要支持 JavaScript 和 Canvas 的浏览器。
- **固定网址访问**：将发布文件上传到 GitHub Pages 或学校网站。访问无需让教师电脑开机；二维码始终指向这个固定网址。网站账号、仓库和托管服务正常维护时可长期使用，不能无条件保证任何第三方服务永远可用。

## 已提供的文件

- `交通灯互动课堂_手机版_长期保存.html`：独立文件，所有互动资源内嵌。
- `交通灯课堂_长期手机版_保存与发布包.zip`：解压后可直接发布。
- 发布包中的 `traffic-light-offline.html`：与独立文件相同的离线备份，英文文件名方便传输。
- `index.html`：网站首页，包含手机版互动与“说明 / 保存”入口。
- `manifest.webmanifest`、`sw.js`、三个 PNG 图标及 `.nojekyll`：添加主屏幕、准备离线访问和静态托管所需文件。

请使用本次的新文件。以前提供的临时网址、局域网网址及二维码不属于长期发布版本。

## 手机怎么用

**推荐：发布为固定网址，再添加到主屏幕。**

1. 安卓在 Chrome 等浏览器打开已发布的网址；通过“说明 / 保存”里的安装按钮（浏览器支持时显示），或浏览器菜单“添加到主屏幕 / 安装应用”添加。
2. iPhone 使用 Safari 打开已发布的网址，点“分享 → 添加到主屏幕”。
3. 从主屏幕打开一次，并保持联网。在“说明 / 保存”中确认显示“已备好离线课堂”，再关闭页面、断网并重新打开验证。
4. 浏览器清理、系统空间不足或自动回收缓存后，离线内容可能丢失；重新联网打开即可准备。主屏幕图标不等于永久保存，仍建议备份 HTML 文件。
5. 微信等内置浏览器的下载与安装功能可能受限，请选择“在浏览器中打开”。

**暂时未发布时：先保存独立文件。**

- 电脑：用 Chrome / Edge 打开 HTML，即可离线操作。
- 安卓：在“文件 / 下载”中选择用支持本地 HTML 脚本的浏览器打开。不同系统、浏览器的支持不同；只能预览或不能点灯时，请使用发布后的网址。
- iPhone：“文件”App 里的 HTML 预览可能不执行交互脚本。请保留文件作为备份，日常使用推荐 Safari 访问固定网址。不能把“文件预览”当作完整浏览器运行环境。
- 网页右上角“说明 / 保存 → 下载离线网页”会发起下载；请在浏览器下载列表确认文件已保存。

## 发布到 GitHub Pages

目前只是发布包，尚未连接你的 GitHub 仓库，没有生成新的公网网址。

1. 登录 GitHub，创建一个公开仓库，例如 `traffic-light-classroom`。免费个人账号通常用公开仓库发布 Pages；其他账号以其支持条件为准。
2. 解压 ZIP，把里面的文件上传到仓库根目录。务必让 `index.html` 位于根目录，不要把 ZIP 文件本身或外层文件夹当作首页上传。
3. 在仓库 **Settings → Pages → Build and deployment** 中，选择 **Deploy from a branch**；分支选择实际上传的分支（通常为 `main`），目录选择 `/(root)`，保存。
4. 等待发布完成，以 Pages 页面给出的真实网址为准。常见格式：`https://你的用户名.github.io/traffic-light-classroom/`。此处是格式示例，不是已经开通的地址。
5. 用手机移动网络和学校 Wi-Fi 分别测试网址，确认点灯、自动循环、保存和主屏幕离线访问正常。
6. 用验证成功的网址生成二维码。二维码自身没有到期时间；能否访问取决于它指向的网站是否存在、网络是否可达。

建议一个月内保持账号、仓库、Pages 开关和网址路径不变。GitHub Pages 在部分网络下可能连接不稳定；如学校网络访问困难，优先考虑学校现有 HTTPS 网站托管，替换二维码中的网址即可。

## 更新网页

- 固定网址路径不变时，二维码无需重做。
- 以后更改首页或图标时，同时更改 `sw.js` 中 `CACHE` 的版本尾缀（例如从 `20261013-v1` 改为新日期版本），提交相关文件。联网重新打开，待更新完成后再关闭并打开，以使用新版缓存。
- 缓存仅覆盖当前网页目录中的指定资源，不会缓存仓库的其他页面。独立 HTML 不加载外部脚本或字体。

## 课堂操作

- 点红灯：只亮红灯，显示红灯梯形图；点绿灯同理。单灯观察保持常亮。
- 点黄灯：只闪黄灯，亮 0.5 秒、灭 0.5 秒，一直闪到切换模式；时钟触点和输出线圈同步变化。
- 点“完整循环”：绿 20 秒 → 黄灯闪 3 次共 3 秒 → 红 15 秒，38 秒一轮。
- 单指拖动旋转，双指或 ＋ / − 缩放；“复位视角”回到正面。
- 在白色程序卡片滑动浏览；点 ⤢ 放大梯形图。

程序板为基本输出回路，使用 Run、Green / Yellow / Red、Clock 常开触点与输出线圈。Clock 示意启用 CPU 时钟字节 MB10 后的 M10.5（1 Hz）。完整 PLC 阶段切换与 TON 同步程序见配套课件。网页时序按标称时间演示，不连接实物 PLC。

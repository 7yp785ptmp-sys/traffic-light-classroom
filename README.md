# 路口里的PLC · 交通灯互动课堂

使用西门子S7-1200梯形图讲解交通灯控制，适合高职课堂。电脑和手机使用同一网页。

课堂网址：https://7yp785ptmp-sys.github.io/traffic-light-classroom/

## 新版功能

- 点击红、黄、绿灯查看对应S/R、TON梯形图。默认只显示程序，点击“解析”后展开通俗讲解，切换灯后收起。
- 单灯观察：红绿常亮；黄灯约亮0.5秒、灭0.5秒持续闪烁；其他两灯关闭。
- 程序单轮：绿20秒 → 黄3秒 → 红15秒 → 三灯全灭。
- 演示循环：网页重复播放上述灯态，供课堂观察。
- 支持电脑拖动、滚轮缩放；手机单指旋转、双指缩放；梯形图可放大查看。
- 截图诊断入口支持分别选择三灯程序截图、预览、移除和清空。
- “说明 / 保存”可以下载离线HTML，支持准备离线课堂及添加主屏幕。

## 梯形图

| 灯 | 启动与输出 | TON及到时动作 |
| --- | --- | --- |
| 绿 | M10.0短时启动，Q0.0(S)保持 | Q0.0驱动T0，PT=T#20s；并联M10.2(S)、Q0.0(R) |
| 黄 | M10.2与M1000.5串联，Q0.1普通线圈 | 从时钟前分支驱动T1，PT=T#3s；并联M10.3(S)、M10.2(R) |
| 红 | M10.3驱动Q0.2(S) | 同条件分支驱动T2，PT=T#15s；并联Q0.2(R)、M10.3(R) |

原S/R程序红灯结束后全灭；“演示循环”是网页重复播放功能。

M10.0应短时接通。CPU中启用MB1000时钟字节后，M1000.5才提供1 Hz节拍，其他程序不可再写入此字节。PLC时钟自由运行，3秒窗口可能截到首尾半拍，不能保证每次恰好三个完整亮灭周期；网页为便于观察按整拍展示。严格要求完整三次时，还需额外同步设计。

网页不连接实物PLC，最终程序需要在TIA Portal / PLCSIM核对。

## 截图诊断状态

当前尚未接入模型服务，截图只能在本机选择和预览，不会给出自动诊断结果。连接配套后端后，可获得逐灯可行性、通俗原因、具体修改建议及报告下载。

GitHub Pages仅托管静态网页，不能运行诊断后端。后端须独立部署；模型API密钥只保存在后端。教师可在“截图诊断 → 教师设置”中填写已部署服务的HTTPS地址和课堂访问码。课堂访问码与API密钥不是同一个东西。

## 保存与更新

index.html是网页首页，traffic-light-offline.html为单文件备份。manifest.webmanifest、sw.js与图标用于离线和主屏幕功能。

首次联网打开后，在“说明 / 保存”中确认离线内容准备好，再断网验证。浏览器清理缓存可能移除离线内容，建议同时备份HTML文件。iPhone的文件预览可能不执行脚本，日常请用Safari访问课堂网址。

固定网址不变时，原二维码无需更换。更新网页时同步更新sw.js的缓存版本；旧页面可联网刷新后重新打开。
